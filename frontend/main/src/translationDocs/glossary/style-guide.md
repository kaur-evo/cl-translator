# Evocon Translation Style Guide

## General Principles

1. **Clarity over creativity** - UI text should be immediately understandable
2. **Consistency** - Use glossary terms consistently across all phrases
3. **Brevity** - Keep button labels and menu items short
4. **Formality** - Use formal "you" form in languages that distinguish (German: Sie, French: vous)

## UI Element Conventions

- **Buttons**: Use imperative form ("Save", "Delete", not "Saves" or "Deleting")
- **Labels**: Use noun form ("Status", not "The status")
- **Confirmations**: Include the action and consequence
- **Placeholders**: Keep variable syntax unchanged: {variable}, {count}, {value}

## Domain-Specific Rules

- **OEE**: Keep as "OEE" in most languages, except French (TRS)
- **Station**: Always translate consistently within each language
- **Shift**: Refers to work period, not keyboard shift key
- **Stop/Downtime**: Use domain meaning (production halt), not general "stop"

## Character Limits

| Element        | Approximate Limit |
| -------------- | ----------------- |
| Button labels  | 20 characters     |
| Tab names      | 15 characters     |
| Toast messages | 60 characters     |
| Tooltip text   | 100 characters    |
